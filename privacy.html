colab-drive 隐私政策

最后更新：2026-10-08

访问哪些数据

经开发者本人授权后，colab-drive 通过 Google Drive API 访问开发者本人 Google Drive 中的文件，仅用于在开发者自己的 Google Colab 运行时中挂载该 Drive 并读写个人项目文件。

数据如何保存与使用

OAuth 授权令牌只保存在开发者本人的电脑和开发者本人的 Colab 运行时中。数据不会被出售、出租或与任何第三方共享，也不会用于广告或画像分析。本应用不收集任何其他用户的数据。

如何撤销授权

可随时在 Google 账号的第三方访问权限页面 撤销本应用的访问权限。

colab-drive Privacy Policy

Last updated: 2026-10-08

Data accessed. With the developer's own authorization, colab-drive uses the Google Drive API to access files in the developer's own Google Drive, solely to mount that Drive inside the developer's own Google Colab runtimes and read/write personal project files.

Storage and use. OAuth tokens are stored only on the developer's own computer and Colab runtimes. Data is never sold, rented, or shared with third parties, and is not used for advertising or profiling. No data of any other user is collected.

Revoking access. Access can be revoked at any time at Google Account third-party access.
